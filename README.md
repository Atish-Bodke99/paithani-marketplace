## 📖 Overview

**Paithani Marketplace** is a web-based platform that connects **sellers** and **buyers** in one place.

- Sellers can register, add products, and manage their store.
- Buyers can browse products, register, and purchase items.

---

## ✨ Features

### 👤 Authentication
- User Registration & Login
- Separate roles for **Seller** and **Buyer**

### 🛒 Buyer Features
- Browse products
- View product details
- Add to cart (if implemented)
- Place orders

### 🏪 Seller Features
- Create and manage shop
- Add, update, delete products
- View orders

### ⚙️ Admin / Backend
- Manage users and shops
- MongoDB database integration
- Session-based authentication

---

## 🛠️ Tech Stack

- **Frontend:** EJS, HTML, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (Atlas)
- **Templating Engine:** EJS
- **Authentication:** Express Session
